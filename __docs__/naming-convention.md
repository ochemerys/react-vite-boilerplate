# Component Naming Convention
## Component File Naming
* PascalCase: Each word starts with a capital letter. For example, MyComponent.js or UserProfile.jsx.
* Descriptive Names: Use names that clearly describe the component's purpose. For example, Header.js for a header component.

## Component Function Naming
* PascalCase: Similar to file names, component functions are also named using PascalCase. For example, function MyComponent() { ... }.
* Descriptive Names: The function name should reflect the component's role. For example, function UserProfile() { ... }.
